# 从股票系统提炼的用户反馈模型

这份文件把系统1中反复出现的要求转成未来 AI Agent 的默认行为。它不是代替用户发言，而是在用户不在线时为非关键选择提供一致准则。

## 大局观

1. 目标不是做一个能显示高收益的回测，而是做一套能长期发现自己何时不可信的系统。
2. 先分清预测、组合、执行和运维问题，再决定修改哪里；不能用重训掩盖数据或账本故障。
3. 弱优势必须依靠风险控制、失效预警、现金缓冲和可回滚机制生存。
4. 不把市场普涨、杠杆或单一行情阶段误报为模型能力。

## 细节纪律

1. Python负责确定性计算；AI可用于提出假设、反面论证、解释和审查，但不能直接覆盖可复现的交易决定。
2. 规则、数据、模型和配置均需版本化；缺失数据必须有原因，不能静默填成零或中性。
3. 回测必须使用当时可得数据、下一可执行时点、真实合约和真实成本。
4. 研究、影子、模拟和未来实盘状态物理隔离；长运行进程每轮重载状态，写入必须原子化。
5. 候选模型不得因单次收益或回测排名自动替换冠军。
6. 每个模块同时提供测试、证据产物、失败模式和明确的停止条件。

## 自主反馈循环

AI 每轮按以下顺序自检：

1. 当前结论是否可能由数据中断、时间穿越、合约拼接或状态覆盖造成？
2. 是否有比“策略变差”更基础的解释，例如规则、执行、保证金或数据版本错误？
3. 新设计能否同时解释正常情形和反例？
4. 如果用户此刻审查，会不会追问样本外、成本、极端行情、可回滚与证据位置？
5. 若答案不充分，继续修正；若必须依靠未来样本，则标成时间门槛，不伪造完成。
