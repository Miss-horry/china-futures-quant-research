# 中国期货量化系统总规范

状态：V0.1 可运行架构基线  
时区：`Asia/Shanghai`  
定位：研究与模拟，不自动连接真实期货账户

## 1. 核心目标

系统交易的是实际月份合约，不交易“主力连续”。研究层可以生成连续指标，但收益、成交、保证金和账本只能来自真实合约。

首版策略是跨品种日频时间序列趋势，用它验证完整基础设施；它是系统探针，不是已证明有效的生产策略。

## 2. 时间与数据

每条数据至少记录 `event_time`、`available_at`、`trading_day` 和来源版本。夜盘自然日期不能替代交易日。收盘信号最早在下一可执行交易时段成交。

数据分为：原始合约行情、标准化合约行情、研究特征、预测账本和交易账本。任何覆盖率不足、重复键、OHLC不合法、结算价缺失或规格版本不匹配都应停止新增风险。

## 3. 合约与换月

合约规格按生效日期版本化，至少包括交易所、品种、乘数、最小变动价位、保证金率、涨跌停、费用、最后交易日和结算方式。

可交易合约选择只使用决策时点已经可得的成交量、持仓量与到期信息。换月是两组真实订单：平旧合约、开新合约。复权连续价格不得进入成交或资金账本。

## 4. 账户与结算

账户同时维护余额、未结算盈亏、保证金、可用资金和压力后缓冲。每日按结算价逐日盯市；保证金按名义价值计算。开仓前检查交易所/期货公司保证金、组合杠杆和压力损失，不能用最低保证金率反推目标杠杆。

## 5. 风险优先级

风险顺序为：数据与状态完整性 > 能否退出 > 保证金生存 > 组合暴露 > 策略信号。

硬门槛包括最大保证金使用率、最小可用现金、品种集中度、总名义杠杆、两日涨跌停压力和最大回撤。触发硬门槛时只允许减仓。

## 6. 执行仿真

订单状态为 `created -> eligible -> submitted -> partial/filled/rejected/expired`。仿真需处理下一时段成交、最小变动价位、滑点、成交量参与率、涨跌停无法成交、开平仓方向和部分成交。

## 7. 三账本

1. 预测账本：当时观察到什么、模型预测什么；
2. 策略账本：预测如何转成目标风险与具体合约；
3. 执行账本：订单如何成交、成本和结算如何发生。

三账本用关联 ID 连接，但不得互相覆盖。研究、影子、模拟与实盘目录隔离。

## 8. 模型治理

新研究结果只能注册为挑战者。晋级至少要求多折时间滚动验证、成本后收益、压力回撤、多个市场状态、足够影子时长和有效成交；默认禁止自动晋级。

AI可以生成研究假设和反面论证，不能直接修改冠军、保证金规则或账户余额。

## 9. 验收边界

当前可以验收：领域模型、风险/结算/执行正确性、合成端到端闭环、账本与晋级门槛。不能伪造完成：真实数据源稳定性、120个交易日影子表现、真实成交和实盘接口安全性。
